**0–2 minutes:** Extract the full ZIP. Start using START-CARERELAY.cmd, enter Alex / Morning. Confirm the badge says Offline demo · no AI. Nothing needs an account or payment. Keep the startup window open.

**2–4 minutes:** Send `Someone needs to collect the library books.` See zero confirmed responsibilities and an ownership question. Reply `I will collect the library books.` See a proposal, not an assignment. Edit details; add `tomorrow at 5 PM`. Save for confirmation. Confirm responsibility. The right panel and relay change only now.

**4–6 minutes:** Open Why this? Verify literal source quotations and a separate human review. Open History. Start Jordan / Evening through the caregiver name. Ask `What changed?` Check owner Alex, library books and 5 PM. Alex's chat is not in Jordan's conversation. Resume Alex through the recent conversations list.

**6–8 minutes:** Send `I can fold the blankets.` It is tentative, so it must ask for clarification and stay unassigned. Dismiss it. Confirmed library books stay unchanged. Use Settings → Add an entry without AI for unfamiliar wording, with a literal quote; review and confirm separately.

**8–10 minutes:** Stop using STOP-CARERELAY.cmd, then start again. Confirm the library responsibility remains. In Settings, inspect AI usage: no requests should have been made by this walkthrough. You may inspect the Live AI option but do not establish an allowance or approve a request as part of this no-cost test. The separate live workflow requires an active new allowance and an AWS approval popup for every request; cancellation and one-attempt enforcement were tested with an offline transport stub.
