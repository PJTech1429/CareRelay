# CareRelay application

See the [complete README](../README.md) for setup, judge testing, modes, spending safeguards and limitations.

Node 22+; no npm install required. Run `npm start` to start, `npm test` for offline tests. Windows users should use `../START-CARERELAY.cmd` and `../STOP-CARERELAY.cmd`.

The default is Offline demo (bounded grammar, not live AI). Live Kimi requires a separately authorized new allowance and explicit per-request approval.
